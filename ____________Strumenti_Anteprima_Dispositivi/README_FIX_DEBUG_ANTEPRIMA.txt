FIX BAT DEBUG - ANTEPRIMA DISPOSITIVI

1) Copia 01_AVVIA_MENU_ANTEPRIMA_DEBUG.bat dentro la cartella strumenti:
   Strumenti_Anteprima_Dispositivi oppure ____________Strumenti_Anteprima_Dispositivi

2) Fai doppio click sul BAT.

3) Se il Python non si apre, il BAT crea il file:
   log_avvio_anteprima.txt

4) Apri/incolla quel log per capire il problema.

Cause comuni:
- Python non installato o non presente nel PATH
- file anteprima_dispositivi_reali.py mancante o con nome diverso
- file .ps1 mancante o bloccato
- cartella spostata senza tutti i file necessari
