# Media ASD Dojo Yamato - v11.9

## Novità Crop Studio

### Zoom anteprima
Aggiunti tre pulsanti sopra l'anteprima:

- Zoom +
- Zoom -
- Reset zoom

Servono solo per lavorare meglio sul riquadro verde di ritaglio.

### Export in cartella unica
Quando scegli la cartella output e premi:

ESPORTA TUTTE LE IMMAGINI CON PRESET

il programma crea automaticamente una sottocartella unica:

PRESET_PER_SITO_WEB

Dentro questa cartella vengono salvate tutte le immagini esportate, senza dividerle in sottocartelle per preset.

Esempio:

Cartella scelta:
C:/Foto_Gara/WEB

Output finale:
C:/Foto_Gara/WEB/PRESET_PER_SITO_WEB
